# 🌐 HTML & CSS Web Projects

This repository contains two frontend web development projects created using HTML and CSS. 
These projects were developed to practice web design, layout, styling, responsiveness, and user-friendly interfaces.

## 📌 Projects

### 1. 🌍 Travel Website

A modern and responsive travel website featuring beautiful destinations, travel packages, features, and an attractive user interface.

**Features:**
- Travel destinations
- Travel packages
- Features section
- Attractive images
- Responsive layout
- Modern navigation bar
- User-friendly design

### 2. 👤 Portfolio Card

A modern personal portfolio profile card designed to showcase personal information, skills, contact details, and social media links.

**Features:**
- Profile section
- Personal information
- Skills section
- Contact details
- Social media icons
- Modern card design
- Responsive layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome

## 🎯 Concepts Practiced

- HTML structure
- CSS styling
- Flexbox
- Cards and layouts
- Background images
- Typography
- Colors and gradients
- Border radius
- Box shadows
- Responsive web design
- Social media icons

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open the required `index.html` file.
4. Run it using **Live Server** or open it directly in a web browser.
